클로드 요금제 개편, 맥스 20x가 울트라로 바뀌면 무엇이 달라지나요?

2026년 11월 3일· 읽는 시간 7분· 노슈니

클로드 요금제에서 가장 비싼 개인 요금제의 이름과 사용 방식이 바뀌었습니다. 2026년 10월 30일(미국 현지시간) 앤트로픽이 월 200달러 맥스 20x를 울트라(Ultra)로, 월 100달러 맥스 5x를 맥스(Max)로 바꾸고, 인증된 울트라 계정에서는 5시간 단위 사용 제한을 없앤다고 발표했습니다. 가격과 주간 사용량은 그대로라서, 더 많이 쓰게 되는 것이 아니라 쓰는 시간을 자유롭게 몰아 쓸 수 있게 된 변화입니다.

배경에는 이름과 실제 한도의 차이가 있었습니다. 맥스 20x는 5시간 한도가 프로의 20배였지만 주간 한도는 프로의 10배였습니다. AI타임스 보도에 따르면 이름 때문에 주간 사용량도 20배라고 오해한 신규 가입자가 생겼고, 앤트로픽은 혼선에 사과하며 이름을 바꿨습니다.

이 글은 클로드 프로나 맥스를 쓰고 있거나 업그레이드를 고민하는 비개발자·직장인을 기준으로 씁니다. 무엇이 바뀌었는지, 5시간 제한이 풀렸는지 확인하는 법, 내 사용 패턴에 맞는 요금제를 순서대로 정리했습니다.

01 무엇이 발표됐나요?

개인 유료 요금제 두 개의 이름이 바뀌고, 그중 울트라에서만 5시간 제한이 사라졌습니다. 기존 가입자는 아무것도 하지 않아도 새 이름으로 자동 전환되고 가격도 같습니다. 클로드 공식 X 계정은 "구독자라면 따로 할 일은 없다"고 안내했습니다.

11월 3일 기준 공식 요금표를 정리하면 이렇습니다.

요금제월 요금(웹 결제)5시간 한도주간 한도월 API 크레딧
프로(Pro)20달러 (연간 결제 시 월 17달러)기준(1배)기준(1배)없음
맥스(Max) · 구 맥스 5x100달러프로의 5배프로의 5배100달러
울트라(Ultra) · 구 맥스 20x200달러없음 (인증된 계정)프로의 10배200달러

표를 옆으로 밀어서 보실 수 있습니다.

표시 가격은 웹 결제 기준이며 세금은 포함되지 않습니다. 모바일 앱에서 결제하면 앱 마켓에 따라 가격이 다를 수 있습니다. 공식 문서에 한국만 따로 다르게 적용한다는 내용은 나와 있지 않습니다.

02 기존 맥스 20x와 무엇이 달라지나요?

달라진 것은 사용량을 나눠 쓰는 방식이지 총량이 아닙니다. 클로드 유료 요금제에는 한도가 두 겹으로 걸려 있습니다. 첫 메시지를 보낸 순간부터 5시간 동안 쓸 수 있는 양(세션 한도)과, 매주 정해진 시각에 초기화되는 일주일치 양(주간 한도)입니다.

비유로 보면

주간 한도는 일주일치 물이 담긴 큰 물통이고, 5시간 한도는 한 번에 따라 마실 수 있는 컵입니다. 예전에는 물통에 물이 남아 있어도 컵이 비면 5시간을 기다려야 했습니다. 울트라는 컵을 없애고 물통에서 바로 마시게 한 것입니다. 물통 크기는 그대로입니다.

  • 그대로인 것: 월 200달러 가격, 프로의 10배인 주간 한도
  • 바뀐 것: 이름(맥스 20x → 울트라), 인증된 계정의 5시간 제한 해제
  • 맥스(구 맥스 5x): 이름만 바뀌고 5시간·주간 한도 모두 프로의 5배 그대로

그래서 하루에 몰아서 오래 작업하는 사람에게 체감이 큽니다. 예를 들어 클로드 코드로 사이트를 만들거나 코워크(Cowork)에 긴 보고서 작업을 맡기다가 5시간 한도에 걸려 멈추던 상황이, 인증된 울트라 계정에서는 주간 한도가 남아 있는 한 생기지 않습니다. 반대로 매일 조금씩 쓰는 사람에게는 달라지는 점이 거의 없습니다.

클로드 웹, 데스크톱 앱, 클로드 코드에서 쓴 양은 모두 같은 한도에서 차감됩니다. 채팅에서 많이 쓴 날은 클로드 코드로 쓸 수 있는 양도 줄어듭니다.

03 인증된 계정은 무엇이고, 내 계정은 어떻게 확인하나요?

인증은 앤트로픽이 자동으로 합니다. 고객센터 안내에 따르면 계정 이력과 결제 이력 같은 요소로 울트라 계정을 자동 확인하고, 확인이 끝나면 임시 제한을 알아서 풀어 줍니다. 사용자가 신청하는 절차는 없습니다.

공식 X 안내 기준으로 기존 가입자 대부분은 발표 당일부터 적용됐고, 새로 가입한 계정은 부정 사용과 사기를 막기 위해 인증 전까지 임시 제한이 남습니다. 제한이 풀리면 이메일로 알려 줍니다.

5시간 제한이 풀렸는지 확인하는 법

  1. 클로드에서 설정(Settings)으로 들어갑니다.
  2. 사용량(Usage) 메뉴를 엽니다.
  3. 현재 세션(Current session) 막대가 보이지 않으면 인증된 계정입니다. 막대가 보이면 아직 임시 제한이 걸려 있는 상태입니다.

결제할 때 휴대전화 번호를 인증하는 것은 별개의 절차입니다. 고객센터는 전화번호 인증만으로는 이 제한이 풀리지 않는다고 안내합니다.

04 비개발자·직장인은 어떤 요금제를 고르면 되나요?

기준은 얼마나 많이보다 어떻게 몰아서 쓰는지입니다. 설정의 사용량 화면에서 최근에 어떤 한도에 먼저 걸렸는지부터 보면 답이 빨리 나옵니다.

내 사용 패턴맞는 요금제
하루 몇 번 질문하고 문서·메일을 다듬는 정도프로. 한도에 거의 걸리지 않는다면 올릴 이유가 없음
매일 코워크·클로드 코드를 쓰고, 5시간 한도와 주간 한도에 둘 다 자주 걸림맥스. 두 한도가 모두 프로의 5배로 늘어남
주 1~2일 몰아서 오래 작업하고, 5시간 한도에 걸려 흐름이 자주 끊김울트라. 주간 한도 안에서 쉬지 않고 이어서 작업 가능
직접 앱이나 자동화를 만들어 클로드 API를 쓸 계획이 있음맥스 또는 울트라. 매달 API 크레딧(100달러/200달러)이 따로 나옴

표를 옆으로 밀어서 보실 수 있습니다.

요금표에는 상위 모델인 페이블(Fable) 사용 조건도 다르게 적혀 있습니다. 프로는 사용량 크레딧을 따로 결제해야 하고, 맥스와 울트라는 주간 한도의 절반까지 포함됩니다. 페이블을 자주 쓴다면 이 차이도 함께 보세요.

API 크레딧이란

클로드 대화창이 아니라, 직접 만든 프로그램이 클로드를 불러 쓸 때 드는 비용을 대신 내 주는 금액입니다. 고객센터 안내 기준으로 터미널·데스크톱 등에서 대화하듯 쓰는 클로드 코드에는 쓸 수 없습니다. 개발 계획이 없다면 요금제를 고르는 이유로 보지 않아도 됩니다.

05 주의할 점과 팀·회사에서 볼 부분은?

가장 흔한 오해는 울트라가 사용량 무제한이라는 생각입니다. 5시간 제한만 없어졌을 뿐 주간 한도는 그대로이고, 앤트로픽은 용량 관리를 위해 주간·월간 상한이나 모델별 제한을 추가로 걸 수 있다고 명시합니다. 주간 한도를 다 쓰면 다음 초기화까지 기다리거나 사용량 크레딧을 추가로 사야 합니다.

  • 울트라와 맥스는 월 결제만 됩니다. 연간 결제는 프로만 가능합니다.
  • 맥스에서 울트라로 올리면 남은 기간만큼 일할 계산으로 청구됩니다.
  • 신규 가입 직후에는 인증 전까지 임시 5시간 제한이 남을 수 있습니다.

이번 변경은 개인 요금제 이야기입니다. 회사에서 여러 명이 쓴다면 개인 울트라를 여러 개 결제하기보다 팀(Team) 요금제를 먼저 비교해 보세요. 요금표 기준 팀 요금제는 표준 좌석과, 표준 좌석보다 5배 많이 쓸 수 있는 프리미엄 좌석을 섞어 살 수 있고, 결제와 관리를 한곳에서 합니다. 요금제를 고르기 전에 누가 어떤 업무에 얼마나 쓰는지부터 정리해 두면 과하게 결제하는 일을 줄일 수 있습니다.

자주 묻는 질문

맥스 20x를 쓰고 있었는데 따로 바꿔야 하나요?

아니요. 기존 맥스 20x 가입자는 같은 가격(월 200달러)으로 울트라에 자동 전환됩니다. 맥스 5x 가입자도 이름만 맥스로 바뀌고 따로 할 일은 없습니다.

울트라로 바뀌면 사용량이 늘어나나요?

주간 사용량은 늘지 않습니다. 울트라의 주간 한도는 예전 맥스 20x와 같은 프로의 10배입니다. 달라진 것은 인증된 계정에서 5시간 단위 제한이 사라져 주간 한도를 원하는 때에 몰아 쓸 수 있다는 점입니다.

클로드 5시간 제한이 풀렸는지 어떻게 확인하나요?

설정의 사용량(Usage) 화면에서 현재 세션(Current session) 막대가 보이지 않으면 인증된 계정입니다. 인증은 자동으로 진행되며, 제한이 풀리면 이메일로도 안내됩니다.

월 100달러 맥스 요금제도 5시간 제한이 없어졌나요?

아니요. 5시간 제한 해제는 인증된 울트라 계정에만 적용됩니다. 맥스는 5시간 한도와 주간 한도 모두 프로의 5배로 기존과 같습니다.

맥스·울트라의 API 크레딧으로 클로드 코드를 쓸 수 있나요?

대화하듯 쓰는 클로드 코드(터미널, IDE, 데스크톱, 웹)에는 쓸 수 없습니다. API 크레딧은 클로드 API, 콘솔 플레이그라운드, 에이전트 SDK처럼 직접 만든 앱과 에이전트에 쓰는 금액입니다.

마치며

이번 클로드 요금제 개편의 핵심은 이름 정리와 5시간 제한 해제입니다. 울트라는 사용량을 더 주는 요금제가 아니라, 같은 주간 사용량을 끊기지 않고 몰아 쓸 수 있게 해 주는 요금제가 됐습니다. 맥스와 프로는 이름 외에 달라진 것이 없습니다.

업그레이드를 고민한다면 먼저 설정의 사용량 화면에서 내가 5시간 한도에 걸리는지, 주간 한도에 걸리는지 확인해 보세요. 5시간 한도에 자주 막힌다면 울트라를, 둘 다 부족하다면 맥스를, 둘 다 여유롭다면 지금 요금제를 유지하는 편이 맞습니다.
