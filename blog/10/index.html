챗GPT 이미지 2.6, 무엇이 달라졌나요? GIF 만들기와 편집 프롬프트 정리

2026년 11월 8일· 읽는 시간 7분· 노슈니

챗GPT 이미지 2.6이 나오면서 챗GPT로 만드는 이미지가 더 빨라지고, 움직이는 GIF까지 만들 수 있게 됐습니다. 2026년 11월 4일 오픈AI가 새 이미지 모델 Images 2.6을 챗GPT, 코덱스(Codex), API에 공개했습니다. 핵심은 세 가지입니다. 생성 속도가 이전보다 50% 빨라졌고, 여러 번 고쳐도 캐릭터와 제품의 세부 모습이 더 잘 유지되며, GIF 만들기와 참조 이미지 저장 기능이 추가됐습니다.

오픈AI에 따르면 지금 챗GPT, 코덱스, API에서 만들어지는 이미지는 일주일에 40억 개, 하루 평균 5억 개가 넘습니다. 그만큼 많은 사람이 이미 업무에 이미지를 만들고 있다는 뜻이고, 이번 업데이트는 그 과정을 더 빠르고 덜 번거롭게 바꾸는 쪽에 가깝습니다.

이 글은 SNS 콘텐츠, 상세페이지, 강의·보고서 자료를 직접 만드는 비개발자와 마케터를 기준으로 씁니다. 무엇이 바뀌었는지, 어디에 쓰면 좋은지, 오픈AI가 공개한 공식 프롬프트 가이드에서 바로 써먹을 요령은 무엇인지 순서대로 정리했습니다.

01 무엇이 발표됐나요?

챗GPT 안의 이미지 생성 모델이 Images 2.6으로 바뀌었고, 새 기능 두 가지가 함께 들어왔습니다. 따로 설치하거나 설정할 것은 없고, 평소처럼 챗GPT에 이미지를 요청하면 됩니다.

항목내용
발표일2026년 11월 4일 (미국 현지시간)
쓸 수 있는 곳챗GPT와 코덱스의 모든 구독 요금제, 데스크톱·모바일·웹. 공식 발표는 전 세계 제공이라고 밝힘
속도이전보다 50% 빠른 생성

새 기능 1GIF 만들기. 반복 재생되는 짧은 애니메이션을 만들고 재생 속도를 조절해 공유 (순차 적용 중)
새 기능 2참조 이미지 저장. 사진에 이름을 붙여 저장해 두고 다음 대화에서 @이름으로 다시 불러 씀

표를 옆으로 밀어서 보실 수 있습니다.

요금제별 이용 횟수나 무료 플랜의 세부 조건은 공식 발표에 따로 나와 있지 않습니다. GIF 만들기는 순차 적용 중이라 계정에 따라 아직 보이지 않을 수 있습니다.

02 기존 챗GPT 이미지와 무엇이 달라지나요?

가장 크게 달라지는 것은 고치는 과정입니다. 예전에는 한 부분만 바꿔 달라고 해도 인물의 얼굴이나 제품 모양까지 조금씩 달라져, 여러 번 다시 만들어야 하는 경우가 많았습니다. 이번 모델은 편집을 거듭해도 캐릭터, 제품, 브랜드의 세부 요소가 일관되게 유지되도록 개선됐습니다.

  • 더 빨라짐: 같은 요청이라도 결과를 받는 시간이 줄어 여러 안을 비교하기 쉬워짐
  • 덜 흔들림: 배경이나 소품만 바꿔도 주인공의 모습이 그대로 유지됨
  • 움직임 추가: 정지 이미지 대신 반복 재생되는 GIF로 받을 수 있음
  • 다시 올릴 필요 없음: 자주 쓰는 사진을 저장해 두고 이름으로 불러 씀
참조 이미지 저장, 비유로 보면

자주 쓰는 사진을 명함첩에 꽂아 두고 이름으로 부르는 것과 같습니다. 오픈AI 릴리스 노트의 예시처럼 반려견 사진을 "Pepper"로 저장해 두면, 다음 대화에서 사진을 다시 올리지 않고 "@Pepper를 수채화 초상화로 그려줘"라고 요청할 수 있습니다. 브랜드 마스코트나 대표 제품 사진을 저장해 두면 매번 같은 캐릭터로 콘텐츠를 만들기가 쉬워집니다.

03 비개발자·직장인은 어디에 쓰면 되나요?

반복해서 비슷한 이미지를 만드는 일에 먼저 붙이는 것이 좋습니다. 같은 캐릭터, 같은 제품이 계속 등장하는 작업일수록 이번 개선의 효과가 큽니다. 아래는 업무별로 생각해 볼 수 있는 가상 예시입니다.

업무이렇게 써볼 수 있습니다
SNS 운영브랜드 마스코트를 참조 이미지로 저장하고, 손 흔드는 GIF나 요일별 인사 이미지를 같은 모습으로 만들기
상세페이지·쇼핑몰제품 모양과 로고는 그대로 두고 배경만 계절이나 행사 분위기에 맞게 바꾸기
카드뉴스·포스터제목 문구를 따옴표로 정확히 지정해 표지 이미지를 만들고, 철자만 직접 확인하기
강의·보고서 자료손으로 그린 스케치를 올려 설명용 캐릭터를 만들고, 단계별 동작을 짧은 GIF로 보여주기

표를 옆으로 밀어서 보실 수 있습니다.

오픈AI는 발표에서 마케터와 크리에이터가 캠페인용 마스코트를 움직이게 하거나, 영상 제작 전에 애니메이션 스토리보드로 동작을 미리 구상하는 활용을 예로 들었습니다. 간단한 손 스케치만으로도 움직이는 캐릭터를 만들 수 있다고 소개했습니다.

04 원하는 이미지를 얻으려면 프롬프트를 어떻게 쓰나요?

오픈AI는 11월 7일 개발자 문서에 이미지 2.6용 공식 프롬프트 가이드를 공개했습니다. 개발자용 문서지만 기본 원칙은 챗GPT에서도 그대로 통합니다. 요점은 용도를 먼저 말하고, 바꿀 것과 지킬 것을 나눠 적는 것입니다.

  1. 용도와 결과물을 먼저 말합니다. "광고 이미지"보다 "신제품 아이스커피 광고용 사진, 흰 배경, 유리잔은 가운데"처럼 쓰임새와 구도를 적습니다.
  2. 넣을 글자는 따옴표로 정확히 씁니다. 위치와 굵기, 몇 번 나오는지까지 정하고 "다른 글자는 넣지 마"를 덧붙입니다.
  3. 고칠 때는 바꿀 것만 말하고 지킬 것을 나열합니다. "옷만 검은 재킷으로 바꾸고 얼굴, 표정, 자세, 배경, 조명은 그대로"처럼 씁니다.
  4. 한 번에 하나씩 고칩니다. 여러 부분을 동시에 바꾸기보다 하나 바꾸고 결과를 확인하는 편이 안정적입니다.
  5. GIF는 처음 자세로 돌아오게 합니다. 시작 자세를 정해 두고 카메라가 움직이는지도 적으면 자연스럽게 반복됩니다.
편집 프롬프트 예시

이 제품 사진에서 배경만 바꿔줘. 연말 선물 분위기의 따뜻한 조명과 붉은색 리본 소품을 넣어줘.
제품의 모양, 색, 로고, 각도, 그림자 방향은 그대로 유지해줘. 새 글자나 워터마크는 넣지 마.

GIF 프롬프트 예시

@마스코트가 정면을 보고 서 있다가 오른손을 들어 두 번 흔들고 처음 자세로 돌아오는 반복 GIF를 만들어줘.
카메라는 고정하고, 배경은 흰색 단색으로 해줘. 글자는 넣지 마.

05 주의할 점과 아직 안 되는 것은?

가장 중요한 것은 그럴듯해 보여도 내용이 맞는지는 따로 확인해야 한다는 점입니다. 오픈AI 가이드도 인포그래픽이나 도표는 글자와 숫자뿐 아니라 정보가 사실과 맞는지 직접 검토하라고 강조합니다.

  • 작은 글자와 복잡한 문구는 생성 후 철자와 가독성을 꼭 확인하세요.
  • 플레어·선버스트 선택, 복잡도 같은 고급 설정은 개발자용 API 기준이라 챗GPT 화면에서 직접 고를 수 없습니다.
  • GIF 만들기는 순차 적용 중이라 계정에 따라 아직 보이지 않을 수 있습니다.
  • 실제 인물 사진이나 다른 회사 로고를 쓸 때는 초상권, 저작권, 오픈AI 이용 정책을 먼저 확인하세요.

팀에서 함께 쓴다면 자주 쓰는 프롬프트와 "반드시 지킬 것" 목록(로고 위치, 브랜드 색, 금지 문구)을 문서로 정리해 두세요. 사람마다 다르게 요청하면 결과도 제각각이 됩니다. 이미지 생성도 결국 기준이 있어야 같은 품질로 반복됩니다.

자주 묻는 질문

챗GPT 이미지 2.6은 무료로도 쓸 수 있나요?

오픈AI는 챗GPT와 코덱스의 모든 구독 요금제에서 데스크톱, 모바일, 웹으로 쓸 수 있다고 발표했습니다. 무료 플랜의 이용 횟수 같은 세부 조건은 발표에 따로 나와 있지 않으니 내 계정의 이미지 생성 화면에서 확인하세요.

한국에서도 챗GPT 이미지 2.6을 쓸 수 있나요?

공식 발표는 전 세계(globally)에 제공한다고 밝혔습니다. 한국을 제외한다는 내용은 없습니다.

챗GPT에서 GIF 만들기 기능이 안 보여요.

오픈AI 릴리스 노트 기준 GIF 만들기는 순차 적용 중입니다. 아직 계정에 적용되지 않았을 수 있으니 시간을 두고 다시 확인해 보세요.

플레어와 선버스트 중 무엇을 골라야 하나요?

두 모델 선택은 개발자용 API에서 하는 설정입니다. 챗GPT 화면에서는 직접 고르지 않고 평소처럼 요청하면 됩니다. API를 쓴다면 속도가 중요할 때 플레어, 복잡한 구도나 정밀한 편집이 필요할 때 선버스트가 권장됩니다.

이미지를 고칠 때 자꾸 다른 부분까지 바뀌어요.

바꿀 부분만 말하지 말고 유지할 요소를 함께 나열하세요. 예를 들어 옷만 바꾸려면 얼굴, 표정, 자세, 배경, 조명은 그대로 두라고 적습니다. 한 번에 한 가지씩 고치는 것도 도움이 됩니다.

마치며

챗GPT 이미지 2.6의 핵심은 더 빠르게 만들고, 덜 흔들리게 고치고, GIF로 움직임까지 더할 수 있게 됐다는 점입니다. 특히 같은 캐릭터나 제품이 반복해서 나오는 SNS·상세페이지 작업에서 체감이 큽니다.

지금 바로 해볼 일은 두 가지입니다. 자주 쓰는 마스코트나 제품 사진을 참조 이미지로 저장해 두고, 다음에 이미지를 고칠 때 "바꿀 것"과 "지킬 것"을 나눠서 요청해 보세요.
