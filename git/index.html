수업은 들었는데 혼자 하려니 막막한 분 집 컴퓨터에 다시 깔아야 하는 분 배운 걸 진짜 내 것으로 만들고 싶은 분

먼저, 한마디만

집에 가면 꼭 막히더라고요

안녕하세요, 노슈니예요. 이 노트는 수업을 마치고 집에 가서 혼자 다시 해볼 때 옆에 두고 보는 복습 노트예요. 수업에선 같이 하니까 술술 됐는데, 막상 혼자 앉으면 "어 이거 뭐였지?" 싶죠. 그 순간을 위해 만들었어요.

이미 수업에서 한 번 해본 것들이라 낯설지 않을 거예요. 처음부터 다 읽을 필요 없이, 막히는 부분만 펼쳐서 그대로 따라 하면 돼요.

이 노트 쓰는 법. 위에서부터 차례대로 가도 좋고, 필요한 데만 콕 집어 봐도 좋아요. 집 컴퓨터에 처음 깔 거라면 내 컴퓨터에 갖추기부터, 다 깔려 있으면 플러그인 · 스킬로 바로 가셔도 돼요.

하나, 다시 떠올리면

클로드 코드, 뭐였더라

우리가 평소에 쓰는 claude.ai는 대화창이에요. 질문하면 답을 보여주고, 파일은 하나씩 올려야 하죠. 클로드 코드는 거기서 한 발 더 들어가요. 내 컴퓨터 폴더 안으로 직접 들어와서 파일을 읽고, 정리하고, 결과물까지 만들어 둡니다.

수업에서 말씀드린 비유 기억나시죠? claude.ai가 카톡으로 물어보는 사이라면, 클로드 코드는 우리 집에 와서 같이 책상 정리해주는 사람이에요.

claude.ai (대화창)클로드 코드
파일하나씩 올려야 함폴더째로 알아서 읽음
결과물복사해서 옮기기파일로 딱 저장해 둠
반복 일매번 다시 시켜야한 번 말하면 알아서

둘, 헷갈리지 않게

챗 · 코워크 · 코드 · 터미널, 뭐가 달라요?

이름이 다 '클로드'로 비슷해서 왕초보일 때 제일 헷갈리는 네 가지예요. 역할이 완전히 다르니, 하나씩 보면 쉬워요.

구분한마디로이럴 때 쓰면 좋아요 (예시)
💬클로드 챗
claude.ai · 웹·앱		똑똑한 대화 상대가볍게 묻고, 글·아이디어 다듬기예: "이 캡션 더 친근하게 고쳐줘"
🤝클로드 코워크
Cowork · 데스크톱 앱		일을 통째로 맡기는 비서여러 단계가 필요한 일을 알아서예: "이 자료들 조사해서 보고서로 정리해줘"
💻클로드 코드
Code · 터미널/앱에서 실행		내 컴퓨터에 와서 일하는 동료내 폴더 파일을 직접 다루고 도구·자동화 만들기예: 회의록 정리, 슬랙봇 만들기
⌨️터미널
앱이 아니라 '명령어 창'		클로드 코드를 켜는 '무대'(장소)명령어를 입력하는 까만 창예: claude 쳐서 코드를 켜요
여기만 안 헷갈리면 돼요. '클로드 코드 = 터미널'이 아니에요. 터미널은 명령어를 입력하는 '창'이고, 클로드 코드는 그 창에서 claude라고 쳐서 켜는 '도구'예요.

💻

셋, 집에서도 이런 걸

혼자서도 이런 걸 만들 수 있어요

수업에서 하나 완성해봤으니, 이제 일상 속 귀찮은 일을 하나씩 시켜보세요. 컴퓨터로 하는 일은 거의 다 됩니다.

  • 콘텐츠·SNS — 카드뉴스 자동으로 만들기, 인스타 글·블로그 초안 쓰기
  • 문서 정리 — 흩어진 회의록 수십 개에서 결정사항만 쏙 뽑아 한 파일로
  • 자료 분석 — 긴 PDF·엑셀 한 번에 요약 (엑셀 함수 몰라도 돼요)
  • 나만의 작은 도구 — 자료 모아두는 웹페이지, 슬랙봇, 반복 작업 자동화
"또 뭘 만들지 막막해요." 그럴 땐 거창하게 생각하지 마세요. 이번 주에 제일 귀찮았던 일 하나를 떠올려서 "이거 좀 줄여줘"라고 시켜보는 것부터예요. 수업에서 했던 그 방식 그대로요.

내 컴퓨터에 클로드 코드 설치하기

수업에서 터미널로 깔아봤죠? 집 컴퓨터에도 똑같이 깔아두면 어디서든 쓸 수 있어요. 진짜 복사 → 붙여넣기 → Enter가 전부예요.

  1. 터미널 앱 열기. Cmd+스페이스바로 검색창을 띄우고 터미널이라 친 뒤 Enter.
  2. 설치 명령어 붙여넣기. 아래 한 줄을 복사해서 붙여넣고(Cmd+V) Enter.
    curl -fsSL https://claude.ai/install.sh | bash
    1분 안쪽이면 끝나요.
  3. 터미널 껐다 다시 켜기. 창을 완전히 닫고 다시 열어주세요.
  4. 확인. 버전 번호가 뜨면 성공!
    claude --version
  5. 실행하고 로그인. claude → 브라우저가 열리면 유료 계정으로 로그인 → 끝.
    claude
홈브루(Homebrew)를 쓰는 분이라면 brew install --cask claude-code 한 줄로도 돼요.
  1. PowerShell 열기. 시작 버튼을 오른쪽 클릭 → 터미널 또는 Windows PowerShell 선택. (안 보이면 Win+R → powershell → Enter)
  2. 설치 명령어 붙여넣기. 오른쪽 클릭으로 붙여넣고 Enter.
    irm https://claude.ai/install.ps1 | iex
  3. PowerShell 껐다 다시 켜기.
  4. 확인.
    claude --version
  5. 실행하고 로그인. claude → 브라우저에서 유료 계정 로그인 → 끝!
    claude
윈도우에서 한 가지. 직접 파일·코드 작업을 하려면 Git이 필요할 수 있어요(git-scm.com). WinGet을 쓴다면 winget install Anthropic.ClaudeCode로도 돼요.
설치하다 막혔다면. claude: command not found가 뜨면 대부분 터미널을 껐다 켜면 해결돼요. 그래도 안 되면 claude doctor로 점검, 그래도 안 풀리면 캡처해서 슬랙 채널에 올려주세요.

다섯, 다시 말 거는 법

처음 켰을 때, 이렇게 말 걸어요

작업할 폴더에서 claude를 켜고, 그냥 말로 시키면 돼요. 잘 시키는 요령 세 가지만 다시 짚을게요.

① 두루뭉술 말고, 콕 집어서

✕ 이러면 헤매요

"문서 정리해줘"

✓ 이렇게 콕

"이 폴더 회의록들 날짜순으로 정리하고, 이번 달 결정사항만 뽑아서 요약.md로 저장해줘"

② 한꺼번에 말고, 하나씩

> 먼저 카드뉴스 1번 글만 써줘
  (확인하고)
> 좋아, 이제 2번 글 써줘

③ 파일은 @로 콕 집어주기

마음에 안 들면 그냥 말하세요. "말투를 더 친근하게", "이 부분은 빼줘"처럼 주거니 받거니 다듬는 게 정상이에요.

여섯, 길 안 잃는 법

터미널, 딱 이만큼만 기억해요

터미널이 어려운 게 아니라 '내가 지금 어느 폴더에 있는지'가 헷갈려서 막히는 거예요. 폴더를 '방'이라고 생각하면 쉬워요.

잠깐 — 터미널이 만든 폴더는 어디 있어요?

왕초보가 제일 어리둥절해하는 부분이에요. 결론부터 말하면, 터미널로 만든 폴더 = 진짜 내 컴퓨터 폴더예요. Finder(맥)나 파일 탐색기(윈도우)에서 평소처럼 보이는, 마우스로 우클릭해서 '새 폴더' 만드는 그것과 완전히 똑같은 폴더예요. 터미널은 그저 '마우스 대신 말(명령어)로' 폴더를 만드는 방법일 뿐이에요. 터미널만의 특별한 폴더가 따로 생기는 게 아니에요.

그럼 그 폴더가 어디에 생길까요? 지금 내가 서 있는 폴더(현재 위치) 안에 생겨요. 터미널을 켜면 늘 홈 폴더에서 시작하니까, 켜자마자 mkdir 카드뉴스를 하면 홈 폴더 안에 '카드뉴스' 방이 생기는 거죠.

홈 폴더는 내 이름으로 된 '내 집' 같은 폴더예요. 평소 쓰는 바탕화면·문서·다운로드가 전부 이 안에 들어 있어요.

🏠 홈 폴더 (내 집) 맥: 사용자/내이름 · 윈도우: C:\Users\내이름 ├─ 🖥️ 바탕화면 (Desktop) ├─ 📄 문서 (Documents) ├─ ⬇️ 다운로드 (Downloads) └─ 📁 카드뉴스 ← 방금 mkdir로 만든 폴더가 여기 생겨요!

눈으로 직접 확인하고 싶으면, 지금 있는 폴더를 화면(Finder·탐색기)으로 바로 열 수 있어요. 점(.) 하나가 '지금 이 폴더'라는 뜻이에요.

맥에서 — 지금 폴더를 Finder로 열기

open .

윈도우에서 — 지금 폴더를 탐색기로 열기

start .
이거 하나만 기억하면 안 헷갈려요. 터미널에서 뭔가 만든 뒤 "어디 갔지?" 싶으면, 그 자리에서 open .(맥) 또는 start .(윈도우)를 쳐보세요. 방금 만든 폴더가 화면에 짠 하고 열려요.

핵심 3줄: 방 만들고 → 들어가서 → 클로드 부르기

① '카드뉴스'라는 방(폴더) 만들기

mkdir 카드뉴스

② 그 방으로 걸어 들어가기

cd 카드뉴스

③ 그 방에서 클로드 부르기

claude

다른 작업으로 옮길 땐 cd ..로 방에서 나온 뒤, 새 방을 만들어 똑같이 하면 돼요.

길 잃었을 때 쓰는 두 마디

명령어이런 뜻이에요
pwd"나 지금 어느 방에 있어?" — 현재 위치 보여줘
ls"이 방 안에 뭐가 있어?" — 파일 목록 보여줘
자주 하는 실수 ①. 폴더 이름에 띄어쓰기는 금물. mkdir 카드 뉴스처럼 띄우면 폴더가 두 개로 쪼개져요. 붙여 쓰거나 -, _를 넣으세요. → mkdir 카드뉴스
실수 ②. "폴더가 바탕화면에 안 보여요!" 터미널은 켜면 항상 홈 폴더(~)에서 시작해요. 바탕화면에 만들려면 먼저 이동. → cd ~/Desktop

일곱, 한 번 더 편하게

내 규칙을 기억시키기 (CLAUDE.md)

클로드 코드는 창을 닫으면 대화를 잊어버려요. 그런데 폴더 안에 CLAUDE.md라는 파일을 하나 두면, 켤 때마다 자동으로 읽어서 내 규칙을 기억해요. 매번 같은 설명을 안 해도 되는 거죠.

제일 쉬운 방법은 그냥 클로드한테 만들어 달라고 하는 거예요.

> 이 폴더는 내 인스타 콘텐츠 작업방이야.
> 말투는 친근하게, 과장 표현은 빼고, 항상 한국어로 써줘.
> 이 내용으로 CLAUDE.md 파일을 만들어줘.

한 번 적어두면, 다음부터는 "친근하게 써줘"를 매번 말 안 해도 알아서 지켜요. 콘텐츠 작업이라면 이런 걸 넣어두면 좋아요.

  • 이 폴더가 하는 일 — "인스타 카드뉴스랑 캡션 작업방"
  • 말투·스타일 — "친근하지만 과장 금지, 항상 한국어"
  • 하지 말 것 — "경쟁사 실명 쓰지 않기" 같은 금지선
  • 저장 규칙 — "초안은 drafts/ 폴더에, 파일명은 날짜_주제"
이거 하나면 훨씬 편해져요. 바로 다음 장에서 이걸 더 편하게 쓰는 습관을 알려드릴게요.

여덟, 알아두면 편해요

꼭 알아두면 두고두고 편한 것들

외울 필요 없어요. "아, 이런 게 있었지" 정도만 기억해두면 나중에 큰 도움이 돼요.

새 프로젝트는 항상 /init부터

작업 폴더에서 클로드를 켜자마자 /init을 해보세요. 클로드가 폴더를 쓱 둘러보고 CLAUDE.md(내 규칙 메모장)를 알아서 만들어줘요.

중간에 떠오른 규칙은 #으로 바로 저장. 작업하다 "앞으로 이건 이렇게 해줘" 싶을 때, 메시지 맨 앞에 #를 붙여 적으면 그 내용이 메모리(CLAUDE.md)에 바로 기록돼요.
예: # 캡션 끝엔 항상 "프로필 링크에서 신청" 붙이기

그 밖에 몸에 익히면 좋은 습관

  • 대화가 길어지면 /compact — 느려졌다 싶을 때 한 번 정리(압축)하면 다시 쾌적해져요.
  • 새 일은 /clear로 초기화 — 앞 작업이랑 상관없는 새 일을 시작할 땐 깨끗이 비우고.
  • 실수했으면 Esc 두 번 — 잘못 바뀌었을 때 이전 상태로 되돌리는 안전장치.
  • 큰 작업 전엔 Shift+Tab(Plan 모드) — 여러 파일을 한꺼번에 바꾸기 전에 '계획만 먼저 보기'.
  • 비밀번호·카드번호·키는 절대 입력 금지 — 민감한 정보는 대화창에 적지 않기.
  • 모르면 그냥 물어보기 — "왜 이렇게 해? 다른 방법 없어?" 클로드는 같이 고민하는 파트너예요.

아홉, 남이 만든 걸 빌려 쓰기

플러그인 · 스킬 깔아서 더 편하게

여기가 진짜 신세계예요. 클로드 코드는 기본도 강력하지만, 남이 잘 만들어둔 '능력 묶음'을 깔면 훨씬 편해져요. 저도 '끼리끼리' 같은 걸 터미널에 깔아두니까 일이 확 줄더라고요. 그 까는 법을 알려드릴게요.

스킬 · 플러그인이 뭐예요?

클로드에게 "이런 일은 이렇게 하는 거야"라고 미리 가르쳐둔 능력 묶음이에요. 스마트폰에 앱 깔듯, 필요한 걸 골라 깔면 명령어 하나로 불러 쓸 수 있어요. (스킬 여러 개를 묶어 한 번에 설치하는 게 '플러그인'이에요.)

까는 기본 순서

  1. 마켓(저장소) 한 번 등록. 클로드 코드 안에서 한 줄 입력 — /plugin marketplace add 저장소주소
  2. 원하는 걸 설치. /plugin install로 목록에서 고르거나, 이름을 바로 적어요.
  3. 클로드 코드 재시작. 그래야 새로 깐 게 켜져요.
제일 쉬운 길. 사실 더 쉬운 방법도 있어요. 깃허브 주소를 통째로 붙여넣고 "이거 보고 설치하는 것 좀 도와줘"라고 클로드에게 부탁하면, 알아서 설치를 안내해줘요. 명령어가 헷갈리면 이렇게 하세요.

① 한국 입문자용 플러그인 모음

비개발자·바이브코더를 위해 한국어로 만든 플러그인 모음이에요. 제가 쓰는 끼리끼리도 여기 있어요. API 키 같은 거 없이 깔면 바로 써요.

/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git

열, 만든 걸 24시간 돌리기

레일웨이(Railway) — 클라우드에 켜두는 내 컴퓨터

수업에서 슬랙봇 만들어봤죠? 그런데 봇이 24시간 대답하려면 봇이 계속 켜져 있어야 해요. 내 노트북을 하루 종일 켜둘 순 없잖아요.

그래서 레일웨이를 써요. 레일웨이는 클라우드에 '항상 켜져 있는 컴퓨터' 한 대를 빌려주는 서비스예요. 거기에 봇을 올려두면, 내 노트북을 꺼도 어디서든 봇이 살아서 일해요.

집에서 다시 올릴 땐 이렇게

  1. 봇 코드를 GitHub에 올리기. 클로드 코드가 옆에서 도와줘요.
  2. 레일웨이에서 그 GitHub 저장소를 연결. 마우스 클릭 몇 번이면 돼요.
  3. 레일웨이가 알아서 켜줌. 코드를 가져와 빌드하고 24시간 실행. 보통 몇 분이면 끝.
  4. 이제 슬랙에서 봇을 부르면 언제든 대답해요.

비용은요

처음엔 무료 체험 크레딧($5, 카드 없이 시작)이 있어요. 이후엔 쓴 만큼 내는 방식이고, 작은 봇 하나는 보통 월 $5 안팎이에요. 정확한 가격은 railway.com에서 확인하세요.
