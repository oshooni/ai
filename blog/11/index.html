클로드 페이블 5.2, 무엇이 달라졌고 내 요금제에선 어떻게 쓰나요?

2026년 11월 10일· 읽는 시간 7분· 노슈니

클로드 페이블 5.2는 지금 클로드에서 고를 수 있는 가장 성능 높은 모델이고, 이번 주에는 평소보다 쓰기 쉬워졌습니다. 2026년 11월 9일(미국 현지시간) 앤트로픽이 클로드 페이블 5.2(Claude Fable 5.2)와 클로드 미소스 5.2(Claude Mythos 5.2)를 발표했습니다. 이전 5.1보다 결과물을 최대 30% 빨리 내고, API 가격은 낮아졌으며, 출시 기념으로 프로 요금제도 11월 16일(미국 태평양 시간)까지 페이블을 요금제 한도 안에서 쓸 수 있습니다.

페이블은 앤트로픽이 가장 어려운 작업용으로 내놓는 상위 모델입니다. 지금까지는 맥스·울트라 요금제에서만 기본으로 포함되고, 프로 요금제에서는 사용량 크레딧을 따로 결제해야 쓸 수 있어 비개발자가 써 볼 기회가 적었습니다.

이 글은 클로드를 업무에 쓰는 비개발자·직장인과 회사에서 클로드를 관리하는 담당자를 기준으로 씁니다. 무엇이 나왔는지, 내 요금제에서 어떻게 쓰는지, 평소 쓰던 오퍼스 5.5와 어떻게 나눠 쓰면 되는지 순서대로 정리했습니다.

01 무엇이 발표됐나요?

같은 기반 모델로 만든 두 모델이 동시에 나왔습니다. 페이블 5.2는 사이버보안·생물학 분야의 오남용을 막는 안전장치를 넣어 모든 유료 사용자에게 열었고, 미소스 5.2는 그 안전장치를 일부 푼 버전이라 심사를 통과한 보안·생명과학 기관에만 제공합니다. 일반 사용자가 고르게 되는 모델은 페이블 5.2입니다.

02 페이블 5.1, 오퍼스 5.5와 무엇이 다른가요?

앤트로픽은 코딩, 추론, 이미지·차트 이해가 좋아졌고 설명이 더 명확해졌다고 밝혔습니다. 다만 모든 일에 페이블을 쓰라고 권하지는 않습니다. 대부분의 코딩과 지식 업무는 오퍼스 5.5(Claude Opus 5.5)로 시작하고, 범위가 크고 어려운 일일 때 페이블로 올리라는 것이 공식 안내입니다.

비유로 보면

오퍼스 5.5는 매일 같이 일하는 유능한 팀장이고, 페이블 5.2는 큰 프로젝트가 막혔을 때 부르는 수석 전문가입니다. 전문가는 더 어려운 문제를 풀지만 시간당 비용이 비쌉니다. 그래서 평소에는 팀장에게 맡기고, 판단이 어려운 일만 전문가에게 넘기는 편이 효율적입니다.

업무와 가까운 항목만 골라 앤트로픽이 공개한 점수를 옮기면 이렇습니다.

  • 속도: 페이블 5.1보다 결과물 생성이 최대 30% 빠름
  • 효율: 클로드 앱의 기본 설정(중간 노력도)에서 5.1보다 적은 토큰으로 어려운 작업을 처리
  • 안전장치: 사이버·생물학 안전장치는 유지하면서 불필요한 차단은 5.1보다 약 55% 줄었다고 발표

03 내 요금제에서는 어떻게 쓰나요?

요금제에 따라 평소 조건과 이번 출시 혜택이 다릅니다. 고객센터 문서 두 개(요금제별 페이블 안내, 출시 혜택 안내)를 합쳐 정리했습니다.

페이블 리셋이란

주간 한도 중 페이블 모델에 쓴 양을 되돌려 주는 쿠폰입니다. 5시간 한도가 있는 계정이라면 5시간 한도도 전부 채워 줍니다. 한도 자체를 늘려 주지는 않고, 한 번 쓰면 취소할 수 없습니다. 한도에 걸리기 전에도 쓸 수 있습니다.

페이블 5.2로 바꾸고 리셋 쓰는 법

  1. 대화창의 모델 선택 메뉴에서 "Fable 5.2"를 고릅니다. 기본 모델은 자동으로 바뀌지 않습니다.
  2. 설정(Settings)의 사용량(Usage) 화면에서 페이블에 얼마나 썼는지 확인합니다.
  3. 한도가 부족하면 같은 화면의 한도 리셋(Limit resets)에서 "Reset for free"를 누릅니다.

04 비개발자·직장인은 어디에 쓰면 되나요?

평소 쓰던 오퍼스 5.5로 결과가 아쉬웠던 크고 복잡한 일 한두 개를 골라 이번 주에 페이블 5.2로 다시 맡겨 보는 것이 가장 실용적입니다. 페이블은 한도를 다른 모델보다 빨리 쓰기 때문에, 간단한 질문이나 메일 다듬기에 쓰면 금방 50% 상한에 닿습니다.

  • 자료가 여러 개인 보고서: 흩어진 문서·표를 모아 결론과 근거를 정리하는 일
  • 차트·그림이 많은 자료 읽기: 차트 인식 점수가 가장 크게 오른 영역
  • 숫자 계산이 얽힌 분석: 오라클은 사전 테스트에서 페이블 5.2가 만든 SQL(데이터 조회 명령)이 다른 두 모델과 달리 금액을 맞게 합산했다고 밝혔습니다
  • 막혀 있던 클로드 코드·코워크 작업: 여러 단계로 나뉘는 긴 작업을 계획하고 끝까지 진행하는 능력이 좋아졌다는 것이 공식 설명입니다

요청은 길게 쓰지 않아도 됩니다. 쇼피파이 엔지니어는 느슨한 아이디어를 주고 몇 번 대화하면 "이대로 진행해"라고 맡길 수 있었다고 평가했습니다. 처음에는 목표와 기준만 주고 계획부터 받아 보는 방식이 잘 맞습니다.

요청 예시

첨부한 3개 분기 매출 자료와 고객 설문 결과를 보고, 다음 분기 영업 전략 보고서를 만들려고 해. 바로 쓰지 말고 먼저 보고서 목차와 각 장에 넣을 근거 자료를 계획으로 보여 줘. 숫자는 원본 표에서 계산 과정을 같이 적어 줘.

위 사례와 평가는 앤트로픽이 발표문에 공개한 사전 테스트 참여 기업의 의견입니다. 내 업무에서도 같은 차이가 나는지는 같은 요청을 오퍼스 5.5와 페이블 5.2에 각각 맡겨 비교해 보는 것이 가장 확실합니다.

05 주의할 점과 회사에서 확인할 부분은?

가장 큰 주의점은 사용량입니다. 맥스·울트라도 페이블은 주간 한도의 50%까지만 포함되고, 그 이상은 사용량 크레딧으로 결제하거나 다른 모델로 바꿔야 합니다. 프로 요금제의 일주일 혜택이 끝나면 페이블은 다시 사용량 크레딧으로만 쓸 수 있고, 남은 50% 한도와 리셋은 이월되지 않습니다.

  • 보안 점검·취약점 공격 코드 같은 고위험 사이버 작업과 대부분의 생물학 연구 질문은 차단되고, 대신 다른 클로드 모델(오퍼스 4.8 또는 오퍼스 5)이 답합니다.
  • 페이블 5.2는 앤트로픽이 지정한 "커버드 모델"이라 대화 내용이 안전 점검용으로 최소 30일 보관됩니다. 데이터 미보관(ZDR) 설정을 쓰던 회사는 적용 범위를 따로 확인해야 합니다.
  • HIPAA 대응 엔터프라이즈 플랜에는 페이블 리셋이 제공되지 않습니다.

회사 계정이라면 관리자 설정을 먼저 보세요. 엔터프라이즈 플랜에서 페이블 5.2는 관리자가 켜기 전까지 꺼져 있지만, 출시 7일 뒤에는 페이블 모델을 이미 허용한 역할에 자동으로 추가되고 페이블로 지정된 기본 모델도 5.2로 바뀝니다. 원하지 않으면 그 전에 관리자가 제외해야 합니다. 보안 정책상 데이터 보관이 어려운 기업을 위해 고객 인프라에 감시 데이터를 두는 엔터프라이즈 프런티어 세이프가드도 비공개 베타로 열렸습니다. 새 모델이 나올 때마다 누가 어떤 모델을 어떤 업무에 쓰는지 기준을 정해 두면 비용과 보안 판단이 훨씬 쉬워집니다.

자주 묻는 질문

클로드 프로 요금제에서도 페이블 5.2를 쓸 수 있나요?

네. 출시 기념으로 2026년 11월 16일 오후 11시 59분(태평양 시간, 한국 시간 11월 17일 오후 4시 59분)까지 주간 한도의 50%까지 추가 비용 없이 쓸 수 있고 페이블 리셋도 1회 받습니다. 그 이후에는 사용량 크레딧으로 결제해야 쓸 수 있습니다.

페이블 리셋을 쓰면 사용량 한도가 늘어나나요?

아니요. 이미 페이블에 쓴 만큼을 되돌려 줄 뿐 한도는 그대로입니다. 페이블 50% 상한도 유지됩니다. 5시간 한도가 있는 계정이라면 5시간 한도는 다른 모델 사용분까지 전부 채워집니다.

페이블 5.2와 미소스 5.2는 무엇이 다른가요?

같은 기반 모델입니다. 페이블 5.2는 사이버보안·생물학 오남용을 막는 안전장치를 넣어 모든 유료 사용자에게 제공하고, 미소스 5.2는 심사를 통과한 보안·생명과학 기관에만 제공합니다.

평소에도 페이블 5.2를 기본 모델로 쓰는 게 좋을까요?

앤트로픽은 대부분의 코딩과 지식 업무는 오퍼스 5.5로 시작하고, 크고 어려운 작업일 때 페이블로 올리라고 권합니다. 페이블은 한도를 더 빨리 쓰기 때문에 어려운 작업에만 골라 쓰는 편이 효율적입니다.

페이블 5.2 API 가격은 얼마인가요?

입력 100만 토큰당 8달러, 출력 100만 토큰당 40달러입니다. 최대 2.5배 빠른 빠른 모드는 16달러와 80달러입니다. 클로드 앱 구독 요금과는 별개입니다.

클로드 페이블 5.2는 더 빠르고 저렴해진 최상위 모델이고, 이번 주에는 프로 요금제에서도 추가 비용 없이 써 볼 수 있습니다. 맥스·울트라 사용자는 구독 기간에 따라 페이블 리셋을 1~3회 받아 2027년 3월 8일까지 쓸 수 있습니다. 평소에는 오퍼스 5.5, 어려운 일에는 페이블 5.2로 나눠 쓰는 것이 공식 권장 방식입니다.

프로 요금제라면 11월 17일 오후(한국 시간) 혜택이 끝나기 전에, 오퍼스로 아쉬웠던 큰 작업 하나를 골라 페이블 5.2에 다시 맡겨 보세요. 결과 차이가 크다면 맥스 요금제나 사용량 크레딧을, 차이가 작다면 지금처럼 오퍼스 5.5를 쓰면 됩니다. 회사 관리자라면 출시 7일 뒤 자동 적용되기 전에 모델 허용 설정부터 확인해 두세요.
