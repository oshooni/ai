둘, 헷갈리지 않게

클로드 챗 · 코워크 · 코드,
뭐가 달라요?

이름이 다 '클로드'라 처음엔 헷갈려요. 오늘 우리가 쓸 건 클로드 코드예요. 셋을 한 번에 정리하면 이래요.

구분한마디로이럴 때 쓰면 좋아요
클로드 챗claude.ai · 웹·앱똑똑한 대화 상대가볍게 묻고, 글·아이디어 다듬기예: "이 캡션 더 친근하게 고쳐줘"
클로드 코워크Cowork · 데스크톱 앱일을 통째로 맡기는 비서여러 단계가 필요한 일을 알아서예: "이 자료들 조사해서 보고서로 정리해줘"
클로드 코드Code · 오늘 우리가 쓸 것내 컴퓨터에 와서 일하는 동료내 폴더 파일을 직접 다루고 웹사이트·도구 만들기예: 오늘의 심리테스트 웹사이트 만들기
비유 하나. claude.ai가 카톡으로 물어보는 사이라면, 클로드 코드는 우리 집에 와서 같이 웹사이트를 뚝딱 만들어주는 사람이에요. 오늘은 데스크톱 앱 안에서 이 '코드'를 켜서 함께 만들 거예요.

셋, 잘 시키는 법

STICC — 프롬프트 잘 쓰는 순서

클로드는 '어떻게 설명하느냐'에 따라 결과가 확 달라져요. 복잡한 걸 시킬수록 아래 순서로 말해주면, 클로드가 체계적으로 접근해서 훨씬 좋은 결과를 줘요.

이 순서대로 설명하면 돼요

복잡한 문제일수록, STICC 순서로 설명하면 AI가 체계적으로 접근하고 해결해요.

S
Situation 상황
지금의 상황과 배경을 설명해요.
T
Task 과제
해결해야 할 과제를 정의해요.
I
Intent 의도
그 과제로 무엇을 이루고 싶은지 의도를 밝혀요.
C
Concern 제약
해결 중 생길 수 있는 장애물·제약을 알려줘요.
C
Calibration 조정
결과를 어떻게(형식·톤·수준) 맞춰갈지 조정해요.

내 프롬프트를 STICC로 업그레이드하기

이미 쓴 프롬프트가 있다면, 아래를 복사해 붙여넣고 맨 아래에 내 프롬프트만 끼워 넣으면 클로드가 알아서 다듬어줘요.

복사해서 클로드에 붙여넣기
아래는 내가 앞으로 프롬프트를 작성할 때 적용하고 싶은 STICC 방법론이야.

[STICC 방법론]
S (Situation) - 현재 상황과 배경 설명
T (Task) - 해결해야 할 과제 정의
I (Intent) - 이 과제를 통해 이루고 싶은 목표와 의도 설명
C (Concern) - 고려해야 할 제약조건, 장애물, 리스크 설명
C (Calibration) - 결과를 어떤 형식·톤·수준으로 맞출지 조정

이제 내가 아래에 작성한 기존 프롬프트를 STICC 방법론에 맞게 재구성해줘.
단순히 형식만 바꾸지 말고,
1. 부족한 정보를 찾아 보완하고
2. AI가 더 좋은 결과를 낼 수 있도록 질문 구조를 개선하고
3. 목적이 더 명확하게 전달되도록 수정하고
4. 출력 형식까지 구체화해서
'최종 실행용 프롬프트' 형태로 업그레이드해줘.

[기존 프롬프트]
(여기에 기존 프롬프트 붙여넣기)
작게라도 이 3가지만. ① 두루뭉술 말고 구체적으로 ② 한꺼번에 말고 하나씩 ③ 마음에 안 들면 바로 고쳐달라 하기. 이것만 지켜도 결과가 확 좋아져요.

넷, 직접 만들어보기

실습 — 나만의 심리테스트 웹사이트

오늘의 실습이에요. MBTI 같은 심리테스트 웹사이트를, 내 직업·관심사와 연결해서 만들어봐요. 아래 프롬프트를 복사해서 [ ] 안을 내 상황으로 바꿔 클로드 코드에 넣으면 끝. 뭘 만들지 막막하면 먼저 아이디어 테스트를 해보세요.

실습 프롬프트 · 빈칸을 채워서 사용
오늘 클로드 코드(Claude Code) 수업에서 각자 웹사이트를 만들어 볼 거야. 나는 MBTI 같은 심리테스트 형식의 웹사이트를 만들 거야. 내 직업/관심사와 연결해서, 질문지를 주고 그 답변을 기준으로 결과를 추천해주는 테스트를 만들고 싶어. 참고로 나는 [직업/하는 일]이야. 그래서 [추천하고 싶은 대상]을 결과로 추천해주는 테스트를 만들고 싶어. 아래 조건에 맞춰 완성된 웹사이트 코드를 만들어줘.

- 질문 개수: 약 [5~7]개
- 각 질문마다 [2~4]개의 선택지
- 결과 유형: [3~5]가지 (예: 결과 A, B, C…)
- 답변 점수나 조합에 따라 어떤 결과가 나올지 로직도 함께 설계
- 결과 화면에는 추천 이유와 짧은 설명도 같이 보여주기
- 디자인은 [내 브랜드 톤 / 귀엽고 아기자기 / 깔끔 모던] 분위기로
- 별도 서버 없이 HTML 한 파일로 바로 실행되게

왜 이렇게 구성했는지, 그리고 질문과 결과를 어떤 기준으로 연결했는지도 설명해줘.

예시 버전 — 디저트 카페 사장이라면

이렇게 내 상황을 채우면 돼요. 참고용 예시예요.

예시 프롬프트
오늘 클로드 코드 수업에서 웹사이트를 만들 거야. 나는 MBTI 같은 심리테스트 형식의 웹사이트를 만들 거야. 참고로 나는 디저트 카페를 운영하는 사장이야. 손님의 취향과 그날의 기분을 묻고, 그 답변을 기준으로 우리 가게 디저트를 추천해주는 테스트를 만들고 싶어. 아래 조건에 맞춰 완성된 웹사이트 코드를 만들어줘.

- 질문 6개 (예: 오늘 기분, 단맛 선호도, 따뜻함 vs 시원함, 함께 먹을 음료, 혼자 vs 같이 등)
- 각 질문마다 3~4개 선택지
- 결과 유형 5가지 디저트 (예: 진한 초코케이크형, 상큼 과일타르트형, 포근 푸딩형 등)
- 선택지 점수 조합으로 결과가 정해지는 로직 설계
- 결과 화면에 추천 디저트, 추천 이유, 어울리는 음료까지 표시
- 디자인은 우리 가게처럼 귀엽고 따뜻한 파스텔 톤
- HTML 한 파일로 바로 실행되게

질문과 결과를 어떤 기준으로 연결했는지도 같이 설명해줘.
완성 예시를 보고 싶다면 황홀스레 디저트 테스트를 열어보세요. 오늘 우리가 만들 결과물이 이런 느낌이에요.

다섯, 아이디어가 필요하면

미션 — 뭘 만들지 클로드에게 물어보기

"난 뭘 만들지 모르겠어" 싶을 때 쓰는 미션이에요. 클로드에게 나한테 맞는 웹사이트를 추천받아, 그중 하나를 골라 만들면 돼요.

미션 프롬프트
오늘 클로드 코드(Claude Code) 관련 클래스를 진행하고 있는데, 클로드 코드에서 각자 웹사이트를 만들어 볼 거야. 이때 누구나 만들기 무난하면서도 실용적인 웹사이트 3개를 추천해줘. 왜 그런 웹사이트들을 추천했는지 그 이유도 함께 알려줘.

(추가 예시) 참고로 나는 카페를 운영하는 사장이야. 발주, 매출 관리, 온라인 판매, 직원 출퇴근, 급여 관리 등에 관심이 많아. 내가 하는 일에 관련된 걸로 추천해줘.
팁. 괄호 안 '(추가 예시)' 부분을 내 직업·관심사로 바꾸면 나에게 딱 맞는 추천이 나와요. 마음에 드는 걸 하나 골라 위 실습 프롬프트에 넣어 만들면 됩니다.
